# Wellora — Healthcare & Wellness Website Template

A premium, modern healthcare and wellness website template built with Next.js, TypeScript, and Tailwind CSS. Designed with a refined dark interface, elegant typography, and a responsive layout.

## Overview

Wellora is a modern website template for healthcare providers, wellness brands, and personalized care businesses. It combines a clean visual identity with thoughtful interactions and reusable components to deliver a polished user experience across devices.

## Features

* Responsive layouts for desktop, tablet, and mobile
* Premium dark theme with golden-yellow accents
* Glassmorphism navigation with scroll-aware styling
* Smooth animations powered by Framer Motion
* Reusable React components
* Contact popup interface
* Centralized design tokens and typography
* Accessible navigation and reduced-motion support
* Modern Next.js App Router architecture

## Tech Stack

* **Framework:** Next.js
* **Library:** React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Package Manager:** npm

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Bishoy-Morgan/wellora-wellness-template.git
```

Navigate to the project directory:

```bash
cd wellora-wellness-template
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Customization

Wellora uses centralized design tokens for colors, typography, spacing, and other design properties, making it easy to adapt the visual identity to different healthcare and wellness brands.
